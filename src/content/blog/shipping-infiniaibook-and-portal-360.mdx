## What's new in InfiniAIBook

These changes follow the October 23 update to my [InfiniAIBook field guide](/blog/open-notebook-self-hosted-research-notebook/).

### Microsoft Learn: saved sources or live context

Open **Add sources → Microsoft Learn** to search documentation through the public Microsoft Learn <Term def="A small service that gives AI apps a standard way to reach outside tools and data.">Model Context Protocol ("MCP") server</Term>. No extra key is needed, just internet access to `learn.microsoft.com`.

- **Import pages.** Save full pages for chat, Studio, live discussions, and library-wide search. Existing pages are marked; duplicates are refused.
- **Use live Microsoft Learn in chat.** Off by default for each notebook. Every question searches Learn alongside your selected sources, without saving results as sources. Citations retain the exact excerpt and link to the original page, even if it changes.

Live mode works only in notebook chat; import pages for Studio or live discussions. Chat reports Learn connection failures. **Search web** now tries Bing's public <Term def="A feed format that lets tools read a website's new content automatically.">Really Simple Syndication ("RSS")</Term> search before falling back to configured search keys.

### Training videos: animation controls and visible progress

**Animation controls.** Under **Design → Animation**, choose **None**, **Light (transitions only)**, or **Full**. Four toggles control transitions and fades, picture push-ins, sequential bullets, and presenter movement. Changes apply to the preview and exported MP4 without rendering the presenter again.

**Progress and failures.** Training-video composition shows a progress bar; motion-explainer animation shows a percentage. Failed training-video renders name the preparation step that failed.

### Optional HyperFrames rendering

[HyperFrames](https://github.com/heygen-com/hyperframes) is an optional <Term def="The part of an app that turns a script and pictures into a finished video file.">renderer</Term> for motion explainers and training videos. It renders animated web pages frame by frame in Chrome, with sharper text captions in training videos.

Enable it with `MOTION_RENDERER=hyperframes` or `TRAINING_RENDERER=hyperframes` in `.env.local`, your private local settings file. Only the final rendering step changes. If it can't run, the app uses its built-in Python renderer and notes the fallback.

HyperFrames requires <Term def="A free command-line tool that converts and combines audio and video.">ffmpeg</Term> and downloads Chrome on first use. Neither HyperFrames nor Chrome is included in the <Term def="A tool that packages an app and everything it needs into a container so it runs the same way on any machine.">Docker</Term> image.

### Smaller changes worth knowing

- **Help and About.** **? Help** groups topics by workflow and links to the docs. About includes license and third-party notices.
- **YouTube transcripts.** Imports without public captions point to Gemini for recovery and explain browser-cookie limits.
- **Spending ceilings.** The daily ceiling reserves avatar-rendering budget, scales speech and chat estimates by size, and applies by default with paid Azure AI Speech.
- **An agent skill.** A <Term def="Reusable instructions an AI coding assistant loads for a matching task.">skill</Term> covers installation, configuration, and scripting for GitHub Copilot, Claude Code, Codex, or Cursor.

<Screenshot
  src={helpTopics}
  alt="InfiniAIBook Help dialog with five topic groups as buttons, the Notebooks and workspace group open, and collapsed topics under Sources and evidence including YouTube transcripts and Import Microsoft Learn pages."
  caption="The refreshed Help dialog, grouped by task. Each topic expands in place and links to the full docs."
/>

The skill is <Term def="Plain text with simple formatting marks, such as # for a heading.">Markdown</Term>, with no scripts. Install it and choose your coding assistants:

```bash
npx skills add russrimm/InfiniAIBook --skill infiniaibook
```

It instructs agents to keep keys in `.env.local`, bind the server to `127.0.0.1`, and confirm before bulk generation.

## What's new in Portal 360°

Since my August 1 [deep dive](/blog/portal-of-portals-deep-dive/), it has merged 594 <Term def="A proposal to combine changes with the main version of a project after review and checks.">pull requests</Term>. The [project page](/projects/portal-of-portals/) has more background.

## What this pace means

For scale, not as a measure of value:

| | InfiniAIBook | Portal 360° |
| --- | --- | --- |
| First <Term def="A saved checkpoint of file changes, with a note about what changed.">commit</Term> | September 18, 2026 | July 29, 2025 |
| Lines of code | About 61,500 (TypeScript and Python) | About 685,000 (TypeScript) |
| <Term def="Programs that check whether the app's code does what it should.">Test</Term> files | 69 | 592 |
| API routes | 65 | 916 |

Counts include tests and blank lines. TypeScript and Python are programming languages. Since August 1, Portal 360°'s TypeScript has roughly 360,000 lines added and 87,000 removed.

Copilot reduces the typing, not the judgment. I still plan the work, review changes, test against a real tenant, and run security reviews. Recently, two changes passed tests separately but failed together after merging. Testing the combined result matters.

InfiniAIBook also includes a [recreation prompt](https://github.com/russrimm/InfiniAIBook/blob/main/docs/recreation-prompt.md) for rebuilding it from an empty folder. It hasn't been tested end to end, but writing a precise product description is useful practice. Keep sensitive data out of unreviewed code; my [vibe-coding lessons](/blog/vibe-coding-lessons/) cover the habits I use.
